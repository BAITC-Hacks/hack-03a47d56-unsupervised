# Умный подбор подрядчиков

MVP-сервис для организаторов мероприятий в Казахстане. По городу, дате, типу события, категории и бюджету подбирает до трёх подрядчиков; язык и длительность можно указать дополнительно.

## Как работает

Сервис исключает занятых на выбранную дату, ранжирует подходящих по условиям запроса и показывает персональное объяснение для каждой рекомендации. Если результатов нет, сообщает причину: в городе нет такой категории или кандидаты не проходят заданные условия.

## Границы MVP

Используется анонимизированный каталог профилей и календарей подрядчиков. Сервис только рекомендует — без бронирования. Повторный запрос с теми же параметрами возвращает тот же порядок результатов.

## Готовая часть: данные и фильтрация

В ветке `gulya` реализована часть участника №1: загрузка и проверка исходных 66 профилей, строгие фильтры, проверка календаря, три различимых исхода, причины исключения и факты для объяснений. Финальные top-3, ranking/AI и интерфейс подключаются следующими участниками.

Требуется Python 3.10+. Внешних зависимостей и API-ключей для фильтрации нет.

```bash
python -m unittest -v test_filtering
python demo_filtering.py --city Алматы --date 2026-09-23 --event-type свадьба --category Ведущий --budget 2000000
```

CLI возвращает весь допустимый пул для ranking, а не финальные карточки. [Контракт модулей, правила, проверенные демо и объяснение для жюри](FILTERING.md).
